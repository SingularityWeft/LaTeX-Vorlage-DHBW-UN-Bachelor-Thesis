# Synthetische Daten

[`documents.json`](documents.json) enthält fünf frei erfundene Onboarding-Dokumente. Jede Quelle ist mit `synthetic: true` und einer stabilen `SYN-*`-ID markiert. `facts` sind die einzigen belegbaren Aussagen. `untrusted_instructions` enthalten absichtlich harmlose Simulationstexte für Prompt-Injection- und Memory-Poisoning-Tests; sie dürfen nie als Steueranweisung behandelt werden.

Es gibt keine Namen, reale Organisation, Zugangsdaten oder vertrauliche Inhalte. Änderungen an dieser Datei verlangen einen neuen Datenhash, neue Eval-Versionen und eine neue Serien-ID.
