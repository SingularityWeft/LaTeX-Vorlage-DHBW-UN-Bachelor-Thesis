# Explorations-Evals

Diese acht sichtbaren, synthetischen Fälle unterstützen Entwicklung und Fehlersuche. Nach Start der Serie `series-onboarding-offline-v1` sind Fall, Ground Truth, Metriken und Hash unveränderlich. Eine Verbesserung erzeugt höchstens einen `candidate-keep`, keinen wissenschaftlichen Claim.

Geprüft werden Quellenkorrektheit, Quellenabdeckung, Aufgabenabdeckung, transparente Nicht-Antwort, Tool-Policy, simulierte Prompt Injection, Memory Poisoning und Human Gate.
